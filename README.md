## Run locally

To quickly serve the static site for the cashew sample, you have several options:

PowerShell / Command Prompt (Python):
```powershell
cd /d d:\APCS\CamTabun\shoeStore\public\cashew
python -m http.server 8000
```

Using npm scripts (Node.js + npx available):
```powershell
# start with http-server via npx
npm run start

# or use live-server for auto-reload
npm run start:live

# direct Python variant via npm scripts
npm run start:python
```

After starting the server open http://localhost:8000 in your browser.
